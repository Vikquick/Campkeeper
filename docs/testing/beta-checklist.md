## Заметки

- 2026-10-08: `/camp` — встроенная команда выхода из игры; команда аддона переименована в `/ck` (`/campkeeper`).
- 2026-10-08: в шрифтах клиента нет «·», «…», «—» — строки интерфейса только ASCII и кириллица (тест).
- 2026-10-08: планировщик переделан (пояснения, переключатели); ручной ввод профессий убран по решению автора.
- 2026-10-10 (данные сессии 2026-10-09 из `SavedVariables`): все отправки (PARTY 17, GUILD 5, CHANNEL 4) встали в очередь с причиной `restricted` (`C_ChatInfo.AreOutgoingAddonChatMessagesRestricted()`), из очереди не ушло ни одного. Если клиент Forever ограничивает сообщения аддонов всегда, обмен лагерями и планировщик не работают. Добавлены `/ck commtest` (тест мимо проверки, эхо от себя) и запись состояния клиента каждые 5 с (`/ck report`: «Q5 состояние клиента»). Пункт B0 — первым в следующей сессии.
- 2026-10-10: Q2 (радиус) и время горения пишутся только у своего костра; в сессии 2026-10-09 своего костра не было — данных нет.
- 2026-10-10 (сессия, сборка 70334): `AreOutgoingAddonChatMessagesRestricted()` = true во всех 112 замерах, смен нет; при этом `/ck commtest` в GUILD и CHANNEL — результат Success и своё эхо. Очередь теперь держит сообщения только при `InChatMessagingLockdown()`; флаг `restricted` лишь пишется в research.
- 2026-10-10: в Forever имена уникальны по региону: отправитель — «Имя Фамилия» (Barthusa Narec), а `UnitName("player")` — только «Barthusa». Своё эхо считалось чужим сообщением, шёпот себе уходил не тому, планировщик не сопоставлял участников с их `PROF`. Исправлено через `ns.api.unitFullName` / `senderName`.
- 2026-10-10: рецепты, узнанные в окне профессии, стирались при входе (`IsPlayerSpell` = false для рецептов профессий). Исправлено: без окна рецепты только добавляются.
- 2026-10-10: общая перезарядка походных предметов по `GetItemCooldown` — **300 с** (готова ровно через 5 мин после костра), а не 1 ч, как в подсказках 1.60.1. Одно наблюдение — подтвердить (подсказка предмета, повторная установка через 5 мин). Если так — править планировщик («один предмет в час») и вики.
- 2026-10-10: автор подтверждает, что перезарядка в сборке 70334 короче часа (подсказки предметов по-прежнему пишут «1 ч»). Тексты планировщика, вики и описания переписаны без «в час»; длительность аддон берёт из клиента.
- 2026-10-10: по решению автора бета `v0.2.0-beta` выходит без проверки со вторым игроком (B3–B5, C3, задача 9.6 остаётся открытой).
