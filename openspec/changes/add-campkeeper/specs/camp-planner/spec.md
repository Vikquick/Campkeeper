# Spec Delta

## Purpose

Помогает группе собрать лучший лагерь: по профессиям участников, числу слотов костра и цели группы подсказывает, кто какой объект ставит.

## ADDED Requirements

### Requirement: Входные данные
Планировщик SHALL принимать профессии и навыки участников (полученные от их аддонов или введённые вручную), число слотов (3, 5 или 10), роль группы (прокачка, подземелье или крафт) и классы участников.

#### Scenario: Участник без аддона
- **WHEN** у участника нет Campkeeper
- **THEN** его профессии и навыки можно ввести вручную

### Requirement: Подбор состава
Планировщик SHALL исключать объекты, бафф которых уже дают классы группы. Остальные объекты он ранжирует по весам выбранной роли и заполняет доступные слоты, выбирая для каждого объекта старший тир, который может поставить хотя бы один участник. Результат детерминирован при одинаковых входных данных.

#### Scenario: Ограничение слотов
- **WHEN** доступно 3 слота, а подходящих объектов 6
- **THEN** в плане 3 объекта с наибольшим весом для роли

#### Scenario: Классовый бафф уже есть
- **WHEN** в группе есть класс, дающий бафф, который перекрывает объект
- **THEN** этого объекта нет в плане

#### Scenario: Старший тир
- **WHEN** один участник может поставить объект T1, а другой — T3 той же профессии, и оба свободны
- **THEN** в плане объект T3, его ставит второй участник

### Requirement: Один предмет на участника
У всех походных предметов, включая костёр, общая часовая перезарядка. Поэтому планировщик SHALL назначать каждому участнику не больше одного предмета. Первым назначается костёр выбранного тира: его ставит участник с наибольшим навыком Кулинарии, которого для этого тира достаточно.

#### Scenario: Один участник умеет всё
- **WHEN** в группе трое, и у одного из них есть все профессии
- **THEN** в плане этот участник ставит только один предмет, а остальные назначения достаются другим или не попадают в план

#### Scenario: Костёр
- **WHEN** выбран костёр 2-го тира, и навык Кулинарии 140 есть только у одного участника
- **THEN** костёр ставит этот участник, и других предметов ему не назначено

### Requirement: Результат плана
Планировщик SHALL выдавать список «участник — объект — тир» и по кнопке отправлять его одним сообщением в чат группы.

#### Scenario: Отправка в чат
- **WHEN** игрок нажимает «В чат группы»
- **THEN** план уходит в чат группы в читаемом виде
