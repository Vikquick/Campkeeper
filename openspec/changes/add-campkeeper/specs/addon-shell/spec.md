# Spec Delta

## Purpose

Оболочка Campkeeper: загрузка в клиенте Forever, точки входа (команда, кнопка миникарты, настройки), локализация интерфейса и отладочный журнал для диагностики в бете.

## ADDED Requirements

### Requirement: Совместимость с клиентом
Аддон SHALL объявлять номер интерфейса Forever 16001 и загружаться в клиенте Forever без ошибок Lua. Зависимости встраиваются в аддон, так что устанавливать отдельно ничего не нужно.

#### Scenario: Чистая установка
- **WHEN** игрок ставит только Campkeeper и входит в игру
- **THEN** аддон загружается без ошибок и без предупреждения об устаревшей версии

### Requirement: Точки входа
Аддон SHALL открывать окно по командам `/ck` и `/campkeeper` и по клику на кнопку у миникарты. Кнопку миникарты можно скрыть. Настройки SHALL быть доступны в разделе «Модификации» системного меню.

#### Scenario: Команда
- **WHEN** игрок вводит `/ck` или `/campkeeper`
- **THEN** открывается или закрывается окно Campkeeper

### Requirement: Встроенные команды клиента не перекрываются
Аддон SHALL NOT регистрировать команды, совпадающие со встроенными командами клиента. В частности, `/camp` — это встроенный выход из игры.

#### Scenario: Игрок вводит /camp
- **WHEN** игрок вводит `/camp`
- **THEN** срабатывает встроенная команда клиента, а Campkeeper её не обрабатывает

#### Scenario: Скрытие кнопки
- **WHEN** игрок выключает кнопку миникарты в настройках
- **THEN** кнопка исчезает, а `/ck` продолжает работать

### Requirement: Локализация
Все строки интерфейса аддона SHALL быть переведены на ruRU и enUS. Для других языков используется enUS. Имена игровых объектов берутся из клиента.

#### Scenario: Немецкий клиент
- **WHEN** игрок с клиентом deDE открывает окно
- **THEN** строки аддона на английском, а имена объектов на немецком

### Requirement: Отладочный журнал
Аддон SHALL вести кольцевой журнал из последних 200 диагностических записей (нераспознанные бонусы, неизвестные объекты, отброшенные сообщения, ошибки API) и показывать его по команде `/ck debug`.

#### Scenario: Переполнение журнала
- **WHEN** в журнал добавляется 201-я запись
- **THEN** самая старая запись удаляется

### Requirement: Сбор данных беты
На время беты аддон SHALL собирать в SavedVariables сведения для открытых вопросов: сырые строки «Бонусов лагеря», расстояние до своего костра при появлении и исчезновении ауры, ауры, появившиеся в лагере, чертежи в сумках, работу addon-сообщений по каналам, заблокированные действия, время горения костра, длительности аур, ошибки установки и наличие ID каталога в клиенте. Данные SHALL храниться только локально и никуда не отправляться. Сбор отключается в настройках, а команда `/ck report` показывает сводку.

#### Scenario: Сводка
- **WHEN** игрок вводит `/ck report`
- **THEN** в чате появляется сводка по каждому разделу собранных данных

#### Scenario: Сбор выключен
- **WHEN** игрок выключил сбор данных в настройках
- **THEN** новые записи не появляются, а собранные раньше сохраняются

#### Scenario: Только локально
- **WHEN** аддон собирает данные беты
- **THEN** ни одно addon-сообщение или сообщение чата не содержит эти данные

### Requirement: Устойчивость к ошибкам API
Вызовы игрового API SHALL выполняться так, чтобы ошибка, секретное значение или незагруженные данные не прерывали работу аддона. Такие случаи пропускаются с повторной попыткой и пишутся в журнал.

#### Scenario: Функция бросает ошибку
- **WHEN** вызов игрового API завершается ошибкой
- **THEN** окно ошибки Lua не появляется, а в отладочном журнале есть запись
